# Contributing

Bug reports, focused improvements, and documentation fixes are welcome.

## Before opening an issue

- Check the existing issues for the same problem.
- Confirm the behavior with the latest code on `main`.
- Remove real advertising IDs, customer data, and complete production URLs from examples.

## Development

Use Node.js 20 or newer.

```bash
npm test
npm run build
```

Please add a test for behavior changes. Keep the runtime dependency-free unless a dependency solves a problem that cannot reasonably be handled with browser APIs.

## Pull requests

Describe the problem, the change, and how you tested it. Keep unrelated formatting or refactoring out of the same pull request.
