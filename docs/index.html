Attribution Tracker

Simple first-touch attribution for JavaScript sites.

This demo captures campaign parameters, click IDs, the landing page, and the external referrer. It stores the result only in this browser session.

Try a campaign visit

Choose an example or edit the URL parameters yourself. The page reloads with test attribution values.

Use it

                
Your consent manager should supply the real consent value.

                
<script src="https://cdn.jsdelivr.net/gh/jasenf/attribution-tracker.js@v0.1.1/dist/attribution-tracker.js"></script>
<script>
  const tracker = new AttributionTracker({
    consent: () => window.cookieConsent === true
  });

  console.log(tracker.getAll());
</script>

            

        


        
The demo passes explicit consent and uses sessionStorage. It does not send the captured values anywhere.
