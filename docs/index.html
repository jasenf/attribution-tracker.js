Use it

                
Your consent manager should supply the real consent value.

                
<script src="https://cdn.jsdelivr.net/npm/@feech/attribution-tracker@0.1.1/dist/attribution-tracker.js"></script>
<script>
  const tracker = new AttributionTracker({
    consent: () => window.cookieConsent === true
  });

  console.log(tracker.getAll());
</script>

            

        


        
The demo passes explicit consent and uses sessionStorage. It does not send the captured values anywhere.
