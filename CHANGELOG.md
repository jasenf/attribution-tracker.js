# Changelog

This project follows [Semantic Versioning](https://semver.org/).

## 0.1.1

- Pinned the jsDelivr script-tag example to the released package version so a stale unversioned CDN lookup cannot break installation.

## 0.1.0

- Added explicit consent configuration with a conservative default.
- Added Global Privacy Control and Do Not Track checks.
- Added ESM and browser builds.
- Added npm and CDN package metadata.
- Added automated tests for capture, first-touch behavior, storage, inference, consent, and clearing.
- Added a GitHub Pages demo and automated repository workflows.
- Disabled diagnostic logging by default.
- Encoded cookie values and added configurable cookie attributes.
